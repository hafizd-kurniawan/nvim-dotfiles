# Wallpapers Directory

This directory contains wallpapers for the Ubuntu BSPWM setup.

## Adding Wallpapers

1. Place your wallpaper images in this directory
2. Supported formats: JPG, PNG, WebP
3. Recommended resolution: 1920x1080 or higher

## Default Wallpaper

The setup will automatically download a default wallpaper during installation.
You can replace it with your preferred wallpaper.

## Setting Wallpaper

The wallpaper is set automatically by the `Theme.sh` script in:
`~/.config/bspwm/src/Theme.sh`

To manually set a wallpaper:
```bash
feh --bg-fill /path/to/your/wallpaper.jpg
```
